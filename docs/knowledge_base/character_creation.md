# Chapter 2: Creating a Character

## Overview
Character creation combines a class, background, species, ability scores, and alignment, then fills in the remaining sheet details. Five steps: choose a class, determine origin (background + species + languages), determine ability scores, choose an alignment, fill in details.

| Class | Likes... | Primary Ability | Complexity |
|---|---|---|---|
| Barbarian | Battle | Strength | Average |
| Bard | Performing | Charisma | High |
| Cleric | Gods | Wisdom | Average |
| Druid | Nature | Wisdom | High |

A "balanced party" (Cleric/Fighter/Rogue/Wizard) can be swapped: Cleric→Bard/Druid; Fighter→Barbarian/Monk/Paladin/Ranger; Rogue→Bard/Ranger; Wizard→Bard/Sorcerer/Warlock.

## Step 4 — Alignment

Two axes: morality (Good/Neutral/Evil) × order (Lawful/Neutral/Chaotic) → 9 alignments (LG, NG, CG, LN, N, CN, LE, NE, CE). PCs default to non-evil; DM approval needed for evil alignment. Unaligned = lacks capacity for moral reasoning (e.g., sharks).

**Personality traits by alignment axis:**

| Axis | d4 traits |
|---|---|
| Chaotic | Boastful, Impulsive, Rebellious, Self-absorbed |
| Good | Compassionate, Helpful, Honest, Kind |
| Evil | Dishonest, Vengeful, Cruel, Greedy |
| Lawful | Cooperative, Loyal, Judgmental, Methodical |
| Neutral | Selfish, Disinterested, Laconic, Pragmatic |

## Step 5 — Fill In Details

- **Saving throws / skills:** proficient = ability mod + proficiency bonus
- **Passive Perception** = 10 + Wisdom (Perception) modifier
- **Hit Points (Level 1):**

| Class | HP Max |
|---|---|
| Barbarian | 12 + Con mod |
| Fighter, Paladin, Ranger | 10 + Con mod |
| Bard, Cleric, Druid, Monk, Rogue, Warlock | 8 + Con mod |
| Sorcerer, Wizard | 6 + Con mod |

- **Initiative** = Dexterity modifier
- **Armor Class** (unarmored) = 10 + Dex mod (or class feature alt.)
- **Attack bonus:** Melee = Str mod + prof bonus; Ranged = Dex mod + prof bonus
- **Spell save DC** = 8 + spellcasting ability mod + prof bonus
- **Spell attack bonus** = spellcasting ability mod + prof bonus

## Multiclassing

- **Prerequisite:** score ≥13 in the primary ability of both current and new class.
- **XP cost:** based on total character level, not per-class level.
- **HP/Hit Dice:** gain new class's HP as "after level 1" values; pool Hit Dice by die type.
- **Proficiency Bonus:** based on total character level.
- **Proficiencies gained:** only a subset of the new class's normal starting proficiencies.
- **Armor Class:** if multiple features offer AC calculations (e.g., Monk Unarmored Defense + Sorcerer Draconic Resilience), pick only one.
- **Extra Attack:** doesn't stack across classes unless a feature explicitly grants more.
- **Spellcasting:** spells prepared calculated per class individually; spell slots calculated from combined caster levels (full casters: Bard/Cleric/Druid/Sorcerer/Wizard full level; Paladin/Ranger half level rounded up; Fighter/Rogue with Eldritch Knight/Arcane Trickster: 1/3 level rounded down) via the Multiclass Spellcaster table.
